We just published a comprehensive, free Kotlin course on the freeCodeCamp.org YouTube channel.

Whether you're targeting Android development, scalable backend services, or cross-platform applications, this course takes you from writing your first line of code to mastering asynchronous programming and reactive streams.

Here are the things covered in this course:

- **Fundamentals & Setup**<br/>Installing IntelliJ IDEA, understanding the JVM, type inference, primitive types, control flow (`when`, loops), and Kotlin’s built-in **null safety**.
- **Functions & Collections**<br/>Default arguments, `vararg`, lambda functions, arrays, collections (`List`, `Set`, `Map`), binary search, and error handling.
- **Modern OOP**<br/>Primary/secondary constructors, `init` blocks, `data` classes, `sealed` classes, companion objects, singletons, delegation, and **extension functions**.
- **Deep-Dive Generics**<br/>Variance (`in`/`out`), upper bounds, the `where` clause, and working around JVM type erasure using `reified` type parameters.
- **Coroutines**<br/>Non-blocking asynchronous programming using `launch`, `async`, `runBlocking`, structured concurrency, timeouts, cancellations, and `withContext`.
- **Kotlin Flows & Reactive Streams**<br/>Cold streams, intermediate and terminal operators (`launchIn`, `asLiveData`), exception transparency, `retry` logic, and lifecycle handling.

The course is completely free and available now [<VPIcon icon="fa-brands fa-youtube"/>on the freeCodeCamp.org YouTube channel](https://youtu.be/nqK3oJ682mQ) (10-hour watch).
