We just published a comprehensive, hands-on video course on the freeCodeCamp.org YouTube channel that will teach you how to build an automated, end-to-end algorithmic trading system from scratch using Python and Django.

This course guides you through engineering a functional, production-style web application called Momentum Trader.

The application evaluates a universe of stocks, calculates momentum scores across a 12-month lookback period (excluding the most recent month to avoid short-term reversals), generates buy/sell trading signals, and executes orders automatically into a brokerage account.

The course walks through the full development stack, breaking down both the quantitative logic and system architecture. :

- Web Framework & Data Modeling with Django
- Market Data Pipeline with Massive
- Brokerage Connectivity with SnapTrade
- Risk-Free Execution with Alpaca
