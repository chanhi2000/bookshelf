Web developers around the world have celebrated ~[Saturnalia (<VPIcon icon="fa-brands fa-tumblr"/>`aardrian`)](https://aardrian.tumblr.com/post/105306017461/heydonworks-happy-to-report-ive-received-the)~ ~solstice~ ~Isaac Newton’s birthday~ Christmas with advent calendars covering web-related topics. As a result, you may recognize some of the ones listed below.

Every year I miss a few on day one, so add a comment or [tweet me (<VPIcon icon="fa-brands fa-x-twitter" />`aardrian`)](https://x.com/aardrian) if you have more to add.

::: info 24 Ways (<VPIcon icon="fa-brands fa-x-twitter" /><code>@24ways</code>)

[<VPIcon icon="fas fa-globe"/>24 Ways](http://24ways.org/), the one that most of this think about for web development calendars, is back again. It’s been going strong since 2005 and based on its history this year should have some good articles.

:::

::: info 24 WAccessibilityays (<VPIcon icon="fa-brands fa-x-twitter" /><code>@24accessibility</code>)

[<VPIcon icon="fas fa-globe"/>24 A11y](http://24a11y.com/) will spend its second year sharing a series of articles on digital accessibility from assorted authors. If its first year was any clue, there will be good stuff coming.

:::

::: info Ladies of Code Advent (<VPIcon icon="fa-brands fa-x-twitter" /><code>@ladiesofcode</code>)

[<VPIcon icon="fas fa-globe"/>Ladies of Code Advent](https://web.archive.org/web/20210306123055/https://codecalendar.dev/) kicks off its inaugural year with a post on accessibility, so I am already a fan.

:::

::: info Lean UXmas (<VPIcon icon="fa-brands fa-x-twitter" /><code>@LeanUXmas</code>)

[<VPIcon icon="fas fa-globe"/>Lean UXmas](http://leanuxmas.com/) collects the most popular articles from the Agile & Lean UX News mailing list, presented throughout the month.

:::

::: info SysAdvent (<VPIcon icon="fa-brands fa-x-twitter" /><code>@SysAdvent</code>)

[<VPIcon icon="fas fa-globe"/>SysAdvent](https://sysadvent.blogspot.com/) is aimed at systems administrators, but there is a some cross-over to web developers. It has posts dating back to 2008, so there is plenty of good material there if you’re too impatient to wait for each day to be revealed.

:::

::: info 24 Days in December (<VPIcon icon="fa-brands fa-x-twitter" /><code>@24DaysInDec</code>)

[<VPIcon icon="fas fa-globe"/>24 Days in December](https://24daysindecember.net/) is a PHP-specific advent calendar. It looks like its goal is to give back to the same community from which the author has learned, which is a good metaphor for the holiday.

:::

::: info Advent of Code (<VPIcon icon="fa-brands fa-x-twitter" /><code>@ericwastl</code>)

[<VPIcon icon="fas fa-globe"/>Advent of Code](http://adventofcode.com/) provides a small programming puzzle every day up to Christmas. They are stand-alone, but supposedly have a general theme. They also use different technologies so there is some variety as well.

:::

::: info 24 Days in Umbraco (<VPIcon icon="fa-brands fa-x-twitter" /><code>@24DaysInUmbraco</code>)

[<VPIcon icon="fas fa-globe"/>24 Days in Umbraco](https://24days.in/umbraco-cms/2019/) is dedicated to the Umbraco CMS. Now in its ninth year (the calendar, not the CMS).

:::

::: info Shape Christmas (<VPIcon icon="fa-brands fa-x-twitter" /><code>@ShapeChristmas</code>)

[<VPIcon icon="fas fa-globe"/>It’s a Shape Christmas](https://itsashapechristmas.co.uk/) is returning. This year will be a selection of favorites from the previous 8 years.

:::

::: info 24 Jours de Web (<VPIcon icon="fa-brands fa-x-twitter" /><code>@24joursdeweb</code>)

[<VPIcon icon="fas fa-globe"/>24 Jours de Web](https://24joursdeweb.fr/) is back (after skipping 2016) as an advent calendar for web folk. Written in French, it is clearly primarily targeted at French speakers, but a round of Google Translate will open it up to far more readers (like me).

:::

::: info Web Accessibility Advent Calendar (<VPIcon icon="fa-brands fa-x-twitter" /><code>@kazuhito</code>)

[<VPIcon icon="fas fa-globe"/>Web Accessibility Advent Calendar 2019](https://adventar.org/calendars/3994) is in Japanese, and thanks to the wonderful powers of Google Translate, I can tell you that anything form poems to posts count as long as they are about accessibility: *"Webアクセシビリティに関する内容であれば、ガチネタでもポエムでも構いません"*. If you know Japanese, I welcome any corrections.

:::

::: info Language a Day (<VPIcon icon="fa-brands fa-x-twitter" /><code>@andrewshitov</code>)

[<VPIcon icon="fas fa-globe"/>Language a Day](https://andrewshitov.com/category/advent-calendar-2019/) will cover the basics of a different programming language every day. Examples will be posted to GitHub.

:::

::: info Java Security (<VPIcon icon="fa-brands fa-x-twitter" /><code>@ripstech</code>)

[<VPIcon icon="fas fa-globe"/>Java Security Calendar 2019](https://web.archive.org/web/20200813171238/https://www.ripstech.com/java-security-calendar-2019/) will give away a daily Java security challenge.

:::

::: info Performance Calendar (<VPIcon icon="fa-brands fa-x-twitter" /><code>@perfplanet</code>)

[<VPIcon icon="fas fa-globe"/>Performance Calendar](https://calendar.perfplanet.com/2019/) hails this as the speed geek’s favorite time of the year, ostensibly because of the tips it has been offering each December since 2009. It isn’t just server optimizations you’ll find here, so don’t shy away because you’re not a system admin.

:::

::: info Data-driven Advent Calendar (<VPIcon icon="fa-brands fa-x-twitter" /><code>@journocode</code>)

[<VPIcon icon="fas fa-globe"/>Data-driven Advent Calendar](https://advent19.journocode.com/) is a bunch of tutorials, interviews, games, and other contributions. It is produced by Journocode, a collection of journalists and computer scientists working in newsrooms across Germany.

:::

::: info Fronteers Advent Calendar (<VPIcon icon="fa-brands fa-x-twitter" /><code>@fronteers</code>)

[<VPIcon icon="fas fa-globe"/>Fronteers Advent Calendar](https://fronteers.nl/blog/categorieen/adventskalender) is a collection of articles on tools, techniques, workflow, and less technical work-related topics. Fronteers is also donating 75 Euros per day to each author’s chosen charity. Also, the articles are in Dutch.

:::

::: info WP snippets til Christmas (<VPIcon icon="fa-brands fa-x-twitter" /><code>@elliottrichmond</code>)

[<VPIcon icon="fas fa-globe"/>WP snippets til Christmas](https://advent.elliottrichmond.co.uk/) is back after a hiatus (it last ran in 2013). Elliott Richmond has asked anyone to submit code, with the only requirement being that it relates to WordPress.

:::

::: info Selfhtml Advent (<VPIcon icon="fa-brands fa-x-twitter" /><code>@SELFHTML</code>)

[<VPIcon icon="fas fa-globe"/>Selfhtml Advent](https://wiki.selfhtml.org/extensions/Selfhtml/example.php/Beispiel:Advent-2019.html) is from Germany’s oldest (since 1995) and largest web design Community. The advent calendar will present tips and examples of its contributors.

:::

::: info Marco’s Extended Advent (<VPIcon icon="fa-brands fa-x-twitter" /><code>@marcoinenglish</code>)

[<VPIcon icon="fas fa-globe"/>Marco’s Extended Advent](https://web.archive.org/web/20200513194615/https://marcozehe.de/2019/11/22/my-extended-advent-calendar/) started in November, and is bringing 30 days of, well, anything. Tips, tricks, links, etc.

:::

::: info JVM Advent (<VPIcon icon="fa-brands fa-x-twitter" /><code>@JavaAdvent</code>)

[<VPIcon icon="fas fa-globe"/>JVM Advent](https://javaadvent.com/) is posting a technical article from various authors related to Java each day.

:::

::: info Perl Advent Calendar (<VPIcon icon="fa-brands fa-x-twitter" /><code>@perladvent</code>)

[<VPIcon icon="fas fa-globe"/>Perl Advent Calendar](http://perladvent.org/2019/) goes all the way back to 2000 (and back then looked a bit more like a traditional advent calendar, too) and has been dispensing tips for Perl developers ever since.

:::

::: info IT Security Advent Calendar (<VPIcon icon="fa-brands fa-x-twitter" /><code>@infowebica</code>)

[<VPIcon icon="fas fa-globe"/>IT Security Advent Calendar](https://infowebica.com/resources/security-advent-calendar/) offers a daily tip for protection of devices, networks and data. If you find the embedded frame does not let you scroll to read the content, [<VPIcon icon="fas fa-globe"/>visit the frame contents directly](https://calendar.myadvent.net/?id=355d9a635dc3f59a803299626f66c48f).

:::

::: info DecEmber (<VPIcon icon="fa-brands fa-x-twitter" /><code>@emberjs</code>)

[<VPIcon icon="fas fa-globe"/>DecEmber](https://web.archive.org/web/20191224175304/https://blog.emberjs.com/tags/december.html), or Countdown to The New Year: 31 Days of Ember Addons, is going further than a 24 day countdown, instead using all of December to highlight a new add-on each day.

:::
