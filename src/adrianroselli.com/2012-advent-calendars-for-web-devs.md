Now that the (Western, my favorite) holiday season is upon us, the tradition of advent calendars whose chocolate is replaced with web-related tips and articles is back. This year’s crop is missing some from last year, but there’s still good stuff to be found.

If you know of any others, please pass them along. For those not returning, I have listed them at the end.

::: info 24 Ways (<VPIcon icon="fa-brands fa-x-twitter"/><code>@24ways</code>)

[<VPIcon icon="fas fa-globe"/>24 Ways](http://24ways.org/), the one that pretty much defines the genre for me, is back again. It’s been going strong since 2005 and based on its history this year should have some good articles.

:::

::: info Performance Calendar (<VPIcon icon="fa-brands fa-x-twitter"/><code>@perfplanet</code>)

[<VPIcon icon="fas fa-globe"/>Performance Calendar](http://calendar.perfplanet.com/2012/) dates back to 2009 (and still defaults to 2011 if you go straight to the domain). It focuses on techniques to speed up your site via scripting, CSS, and general mark-up, along with server tweaks and analysis suggestions.

:::

::: info Perl Advent Calendar (<VPIcon icon="fa-brands fa-x-twitter"/><code>@perladvent</code>)

[<VPIcon icon="fas fa-globe"/>Perl Advent Calendar](http://perladvent.org/2012/) goes all the way back to 2000 (and back then looked a bit more like a traditional advent calendar, too) and has been dispensing tips for Perl developers ever since.

:::

::: info Webkrauts

[Webkrauts has an all German advent calendar](https://webkrauts.de/serien/adventskalender/2012), and it also dates back to 2005. It covers general web topics, but being in all-German readers like me will benefit from a Google Translate version of the page. Suggestion via [<VPIcon icon="fa-brands fa-x-twitter"/>`@patrick_h_lauke`](https://twitter.com/patrick_h_lauke).

:::

::: info 24 Jours de Web (<VPIcon icon="fa-brands fa-x-twitter"/><code>@24joursdeweb</code>)

[<VPIcon icon="fas fa-globe"/>24 Jours de Web](https://24joursdeweb.fr/) has kicked off its first year as an advent calendar for web folk. Written in French it is clearly primarily targeted at French speakers, but a round of Google Translate will open it up to far more readers (like me). Suggestion via [<VPIcon icon="fa-brands fa-x-twitter"/>`@PhilippeVay`](http://twitter.com/PhilippeVay).

:::

::: info Japanese HTML5 Advent Calendar

[<VPIcon icon="fas fa-globe"/>HTML5 Advent Calendar 2012](https://adventar.org/calendars/27) is in Japanese, and thanks to the wonderful powers of Google Translate, it was very little confidence that I suggest it is produced by volunteers who have each picked a day and written something about the web (based on this statement: 登録した日に自分のブログなどにエントリーを書いてください。). If you know Japanese, I welcome any corrections. The site [<VPIcon icon="fas fa-globe"/>Adventar.org](https://adventar.org/) appears to host other advent calendars, some about web technologies, some not.

::: info Web Advent

[<VPIcon icon="fas fa-globe"/>Web Advent](http://web.archive.org/web/20130105105124/http://webadvent.org/2012) is back. I had incorrectly listed it as not returning below, under its original address as the PHP advent calendar. With its name and domain change, it appears to be back again this year and keeping its streak from 2007 going strong.

:::

::: info HTML & CSS Advent

[<VPIcon icon="fas fa-globe"/>HTML & CSS Advent](https://web.archive.org/web/20130102084124/http://advent2012.digitpaint.nl/) uses a rather self-explanatory name. Moving away from last year’s advent-calendar-flap layout and to more of a list of articles, you’ll find some experimentation with cutting-edge (or nearly so) features that may not make into client work just yet.

:::

::: info 12 Devs of Xmas

[<VPIcon icon="fas fa-globe"/>12 Devs of Xmas](https://12devsofxmas.co.uk/) was also listed below as not returning (it has articles from last year), but I misunderstood — it will be starting the day after Christmas and going for 12 days from then. When all the other calendars have wrapped up, you’ll still have one to read.

:::

::: info UXmas

[<VPIcon icon="fas fa-globe"/>UXmas](http://uxmas.com/) is an advent calendar aimed at the user experience community. Coming from Australia, American readers may be thrown just a bit by the schedule. The calendar promises everything from sketches, to articles, to tools, to videos. Found this one via [.net Magazine (<VPIcon icon="fa-brands fa-x-twitter"/>`netmag`)](https://twitter.com/netmag).

:::

::: info Freelancember

[<VPIcon icon="fas fa-globe"/>Freelancember 2012](https://freelancember.com/) is produced by the makers of Freckle time tracking software and targeted squarely at freelancers. Its daily entries will consist of downloadable gifts in the form of PDF worksheets. Think of this as less about web-tech and more about MadLibs for projects. Found this one via [.net Magazine (<VPIcon icon="fa-brands fa-x-twitter"/>`netmag`)](https://twitter.com/netmag).

:::

::: info Mozilla Developer Network Holidays calendar

[<VPIcon icon="fas fa-globe"/>Mozilla Developer Network Holidays calendar](https://thewebrocks.com/mdncalendar2012/) includes brief links to resources or demos and suggests that you can edit them (if they are MDN resources). I had this one listed as non-returning because last year’s address was very generic and the site has no navigation on the home page to direct users here. Perhaps that should be tip #1. ---

:::

::: info She Said It

[<VPIcon icon="fas fa-globe"/>She Said It](https://web.archive.org/web/20130115102034/http://shesaid.it/) is an advent calendar dedicated to providing general tips for the web industry in general, with quotes provided by women in the field. I only discovered this on Christmas Eve eve, so I’ve seen it fully populated by now. This calendar is produced in Sweden, but its contributors hail from everywhere.

:::

::: info 12 Days of Podcasts

[<VPIcon icon="fas fa-globe"/>12 Days of Podcasts](http://web.archive.org/web/20130101102147/http://www.besquare.me/conferences/12-days-of-podcasts/), which I discovered on the day after Christmas, runs from December 26 to January 6, 2013. Each day will have a different audio-only interview with assorted web folks. You can stream them off the site or download the MP3 for later listening pleasure (perhaps during that terrible New Year party you’re attending).

:::

::: info Not Returning

A handful of calendars aren’t returning this year (so far), but content from previous years is still available. These include Font Deck’s [<VPIcon icon="fas fa-globe"/>Adfont Calendar](http://web.archive.org/web/20111126180041/http://adfont-calendar.com:80/), and the [<VPIcon icon="fas fa-globe"/>Fronteers advent calendar](http://fronteers.nl/blog/categorieen/adventskalender) (in Dutch).

::: info Completely Unrelated

I discovered this one this morning and have no idea what to expect (other than the first day so far), but it might worth a look: [<VPIcon icon="fas fa-globe"/>Popperfont’s Sciencegeek Advent Calendar Extravaganza](http://popperfont.net/category/adventcalendar2012/). With such a compelling name, how can you not look?

:::
