## What is Origin?

Starting a new project for me used to mean cobbling together and rehashing code from past work. This year I started to consolidate everything into my own personal boilerplate to kick start front-end development.

“Origin” is my code name for this on-going project (everything needs a name). It’s not a behemoth of code like [<VPIcon icon="fas fa-globe"/>Bootstrap](https://getbootstrap.com/2.3.2/) or [<VPIcon icon="fas fa-globe"/>Foundation](http://foundation.zurb.com/). It’s specifically tailored to suit the websites I make. It will never be complete and it will evolve dramatically as my preferences and needs change.

This is not a framework I expect others to use ‘as is’ but I decided to make it public because:

- A lot of people asked kindly
- I learn from similar projects by other developers
- It will serve as a reference point when discussing particular techniques

If you care to poke around the [code is on GitHub (<VPIcon icon="iconfont icon-github"/>`dbushell/dbushell-Origin`)](https://github.com/dbushell/dbushell-Origin). Or you can see the [<VPIcon icon="fas fa-globe"/>GitHub page](https://dbushell.github.io/dbushell-Origin/) for my starting [<VPIcon icon="fas fa-globe"/>pattern library](https://dbushell.github.io/dbushell-Origin/origin.html). This doesn’t include everything I consider a “best practice” and a lot of things aren’t commented. Make of it as you will — just please don’t include it in a *“10 new resources for developers”* blog post!

If you like the idea of automated builds and need a mature Grunt workflow then give [<VPIcon icon="fas fa-globe"/>Yeoman](http://yeoman.io/) a test drive. For a BEM-style CSS framework there’s [Inuit.css (<VPIcon icon="iconfont icon-github"/>`csswizardry/inuit.css`)](https://github.com/csswizardry/inuit.css). And if you need to prototype something fast, Bootstrap and Foundation have their uses.
